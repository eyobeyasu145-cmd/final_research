# Final Research: Real Estate System Use Case Diagram

This repository contains an interactive use case diagram visualization for an existing Real Estate System, developed as part of a final research project (Chapter 2 — Literature Review).

The interactive diagram illustrates the current functionalities, actors (Property Owner, Client, Agent), and their interactions within a traditional real estate agency context.

## Features

- **Interactive Canvas Diagram:** Built with HTML5 Canvas for smooth and dynamic rendering.
- **Actor Details:** View specific use cases for Property Owners, Clients (Buyers/Tenants), and Agents.
- **Dynamic Relationships:** Hover or click on use cases to dynamically highlight associated actors and `<<include>>` relationships.
- **Modern UI & Animations:** Styled with Tailwind CSS, featuring glassmorphism elements, particle background animations, custom fonts (Space Grotesk, DM Sans), and a responsive layout.
- **Detail Panel:** An informative slide-out sidebar that explains each selected use case in depth.

## Technologies Used

- **HTML5 & Canvas API** for custom diagram rendering
- **Vanilla JavaScript** for state management, interactions, and canvas animations
- **Tailwind CSS** (via CDN) for modern, responsive styling
- **FontAwesome** for icons

## Project Structure

- `indexs.html`: The main interactive Use Case Diagram application.
- `index.html`: A boilerplate HTML page.

## Getting Started

Since this is a pure front-end application, there is no need for a complex environment setup or development servers.

1. Clone the repository:
   ```bash
   git clone https://github.com/eyobeyasu145-cmd/final_research.git
   ```
2. Navigate to the project directory:
   ```bash
   cd final_research
   ```
3. Open the `indexs.html` file directly in any modern web browser to view and interact with the diagram.
